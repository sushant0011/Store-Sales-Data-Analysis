# Store Data — Power BI Analysis Project

Power BI dashboards and reports built on retail store sales data.

## 📁 Project Contents

| File | Description |
|------|-------------|
| `Store_Data.xlsx` | Source dataset used to build the Power BI reports |
| `Overview.pbix` | Overview dashboard summarizing key store metrics |
| `Requirement_4.pbix` | Power BI report for Requirement 4 |
| `Alternate_Req_4.pbix` | Alternate approach/version for Requirement 4 |
| `Table_Visual.pbix` | Report focused on table visualizations |
| `Top-Bottom_5_Analysis.pbix` | Top 5 and Bottom 5 performers analysis |

## 🛠️ Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel

## 🚀 How to View
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
2. Open any `.pbix` file to explore the report/dashboard.
3. `Store_Data.xlsx` can be opened in Excel to view the raw source data.
